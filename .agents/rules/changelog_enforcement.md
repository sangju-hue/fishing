# 작업 이력 의무 기록 가이드라인 (Changelog Enforcement)

**적용 시점**: 이 프로젝트를 수행하는 모든 에이전트(LLM)는 작업 및 대화를 마칠 때 무조건 이 규칙을 따라야 합니다.

**요구사항**:
1. 코드, 선박 정보(`boats.json`), 선사 정보, UI 마크업, 기능 개선 등 **어떠한 형태의 수정이라도 발생했다면 반드시 `GEMINI_HANDOFF.md` 파일에 해당 내역을 추가로 기록해야 합니다.**
2. 특히 낚싯배가 새롭게 추가되거나, 기존 선박/선사 이름이 수정되거나, 새로운 스크래핑 룰이 도입되었을 경우, 변경 날짜(현재 날짜)와 함께 무엇이 왜 변경되었는지 정확히 요약하여 추가하세요.
3. 다음 작업을 수행하는 LLM이 과거 히스토리를 즉각적으로 파악할 수 있도록 리스트(`- `) 형태로 명확하게 정리해야 합니다.
4. 모든 기록은 항상 `GEMINI_HANDOFF.md` 하단에 Append(추가) 하는 방식으로 작성하세요. 기존의 이전 기록을 지우면 절대 안 됩니다.

이 규칙은 낚시배 예약 프로젝트의 유지보수를 위해 사용자가 강력히 요청한 필수 사항입니다.
