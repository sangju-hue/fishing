# 바다자리 · 낚싯배 예약 현황

[👉 웹페이지 열기](https://sangju-hue.github.io/fishing/)

서해 낚싯배의 날짜별 예약 현황과 잔여석을 한눈에 비교할 수 있는 통합 서비스입니다.

## 📌 주요 기능
- **통합 검색 및 필터링**: 원하는 선사·선박 이름과 출항 항구 필터로 맞춤 검색을 지원합니다.
- **빈자리 모아보기**: 원하시는 날짜를 선택하시면 해당 일자의 잔여석(1석 이상)이 있는 배들만 하단에 모아서 보여줍니다. (다중 선택 가능)
- **빈자리 알림 기능**: 원하시는 배에 빈자리가 생겼을 때 ntfy 앱을 통해 실시간 알림을 받을 수 있습니다.

## ⚠️ 유의사항
- 화면에 표시되는 잔여석 숫자는 수집된 정보를 바탕으로 합니다.
- 시스템 통신 지연 등에 따라 실제 예약 현황과 차이가 있을 수 있으므로, **예약 전 반드시 각 선사 홈페이지에서 최종 확인**을 진행해 주세요.
