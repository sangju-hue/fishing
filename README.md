# 바다자리 · 낚싯배 예약 현황

[웹페이지 열기](https://sangju-hue.github.io/fishing/)

서해 낚싯배의 날짜별 예약 현황과 잔여석을 비교하는 페이지입니다. 예약과 최종 확인은 각 선사의 예약현황 페이지에서 진행해 주세요.

## 사용 방법

- 선사·선박 이름 검색과 항구 필터로 원하는 배를 찾습니다.
- 날짜 아래 체크박스를 선택하면 선택 날짜 중 잔여석 1석 이상인 배만 표시합니다. 여러 날짜를 선택할 수 있으며, ‘날짜 선택 해제’로 초기화합니다.
- 표 아래에는 선택 날짜에 빈자리 있는 선사·선박·잔여석과 홈페이지 링크가 표시됩니다.
- 숫자는 확인된 잔여석입니다. 미확인·오래된 정보는 빈자리로 확정하지 않습니다.
- 빈자리 알림은 페이지의 안내에 따라 설정하며, 폰에서 같은 ntfy 토픽을 구독하거나 안내된 텔레그램 연결을 사용합니다. 본인 신청은 신청한 브라우저에서 관리합니다.

## 운영 구조

- 이 저장소에는 웹페이지 운영에 필요한 정적 파일과 공개 예약 데이터만 보관합니다.
- 수집기·스케줄러·알림 처리기·Cloudflare 중계 배포 소스·테스트·작업 기록은 운영자 맥에 보관하며 이 저장소에 게시하지 않습니다.
- 예약 정보는 맥 수집기가 갱신하여 GitHub Pages에 게시합니다. GitHub에서 예약 사이트를 직접 수집하지 않습니다.
- 알림 신청은 Cloudflare 중계를 통해 맥에서 처리합니다. 개인키·인증 토큰·신청 소유자·개인 운영 설정은 공개 파일에 포함하지 않습니다.
- 수집 상태는 별도 `collector-status` 브랜치의 `status.json`에서 제공하며 예약 데이터와 분리됩니다.
- 원본 예약 사이트의 변경·통신 지연으로 일부 정보가 늦거나 미확인일 수 있습니다. 예약 전 선사 홈페이지에서 최종 확인해 주세요.
